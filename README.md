# ⚒️ TorchFoundry

**find your PyTorch workflow.**

TorchFoundry is a Python library designed to simplify and improve everyday workflows when working with PyTorch.
It aims to provide reusable utilities that reduce repetitive code and make machine learning development more convenient.

Make PyTorch development simpler, more reusable, and easier to maintain.
It is available on
[pypi](https://pypi.org/project/torchfoundry/)

### Installation

```bash
pip install torchfoundry
```

### 🎓 Built for Learning
TorchFoundry was created with beginners in mind.

Especially those who want to get into the flow of training machine learning models without being overwhelmed by the complexity that can come with getting started.
The goal is to make the first steps into model development more approachable, allowing learners to focus on understanding the workflow and gradually build confidence in working with PyTorch.

However, simplification comes with trade-offs. 
Abstracting away complexity can introduce limitations and hide implementation details that are important to understand. TorchFoundry is intended as a starting point, not a replacement for learning the underlying concepts. Anyone serious about exploring machine learning should investigate these limitations, understand what happens behind the abstractions, and learn when a more hands-on approach is necessary.
