# Security Policy

## Supported Versions

TorchFoundry is currently under active development. Security updates are provided for the latest stable release.

| Version               | Supported          |
| --------------------- | ------------------ |
| Latest stable release | :white_check_mark: |
| Older releases        | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in TorchFoundry, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use GitHub's private vulnerability reporting feature:

1. Open the TorchFoundry GitHub repository.
2. Navigate to the **Security** tab.
3. Select **Report a vulnerability**, if available.
4. Provide a description of the vulnerability and steps to reproduce it.

Include the following information when possible:

* A description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact.
* Any suggested fixes or workarounds.

## Response

I will review vulnerability reports as soon as possible and work toward providing a fix.

Please allow reasonable time for investigation and resolution before publicly disclosing the vulnerability.

Thank you for helping keep TorchFoundry safe.
